02 · Log Pipeline · active

Parse once. Remap into standard fields.

The live pipeline uses service:sdk-diagnostics @event_name:sdk.error.uncaught. A JSON parser exposes the payload; remappers populate Datadog’s standard error fields. The original log remains available and the pipeline is reversible.
